## 🚀 How to Run

### Prerequisites

Make sure **Python 3.x** is installed on your computer.

You can check your Python version using:

```bash
python --version
```

or:

```bash
python3 --version
```

### 1. Clone the Repository

Open a terminal or command prompt and run:

```bash
git clone https://github.com/patelrahulkumar/TRAININGS-SYSKRITI-PVT.-LTD.git
```

### 2. Navigate to the Python Assignment Folder

```bash
cd TRAININGS-SYSKRITI-PVT.-LTD/Python_Assignment
```

### 3. Choose an Assignment

For example, to open **Task 1**:

```bash
cd "Task_PY200_T1_Average (MMM)"
```

### 4. Check the Python File

List the files inside the folder.

**Windows:**

```bash
dir
```

**Linux / macOS:**

```bash
ls
```

Look for the Python file with the `.py` extension.

### 5. Run the Python Program

Use:

```bash
python filename.py
```

Replace `filename.py` with the actual Python file name.

If your system uses `python3`, use:

```bash
python3 filename.py
```

### Example

If the folder contains a file named:

```text
average.py
```

run:

```bash
python average.py
```
